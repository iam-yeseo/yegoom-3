# 예굼방 아케이드 3 — 승부차기

혼자 하기 게임. 키커가 되어 골키퍼를 상대로 5번 찬다. 자유투·컬링과 같은 원칙이다: **같은 입력이면 언제나 같은 결과**, 한 번에 기록, 서버 재계산.

> 상태: 구현 완료(2026-11-20). 기획서의 "키커/골키퍼 선택 + 확률"은 쓰지 않고, 키커 전용에 **골키퍼를 읽는 타이밍 게임**으로 다시 설계했다. 도전과제는 아직 없다.

## 1. 확정된 결정 (2026-11-20)

| 항목 | 결정 |
| --- | --- |
| 세트 | **3시간마다 킥 5번**. KST **02·05·08·11·14·17·20·23시**에 열린다 |
| 역할 | 키커만. 골키퍼 역할은 없다(6칸 중 하나를 찍는 방식은 선방 확률이 약 17%라 고를 이유가 없었다) |
| 조작 | 휘슬 뒤 10초 안에 공을 잡고 **차고 싶은 쪽으로 쓸어 올리며** 놓는다 |
| 보상 | **1골마다 1점 + 10G** (한 세트 최대 5점) |
| 연습 | 있음. 다섯 번마다 새 골키퍼, 보상 없음 |
| 골키퍼 | 같은 시간대에는 **모두 같은 골키퍼 다섯 명**(칸 번호로 정해짐). 뒤로 갈수록 빠르고 멀리 닿는다 |

## 2. 재미를 만드는 규칙 (`shared/penalty-engine.ts`)

숨은 주사위는 없다. 골키퍼가 **보이는 대로** 움직이고, 결과는 그 순간 골키퍼의 위치·움직이던 방향과 내 킥으로 정해진다.

- 입력은 정수 세 개: `power` 0~100, `aim` −100~100, `t`(휘슬부터 킥까지 ms, 시간 초과는 −1).
- **방향**: 쓸어 올린 방향 그대로. ±80쯤이 골대 기둥이고 그 밖은 벗어난다.
- **세기**: 셀수록 공이 빠르고 높다. 8 이하는 땅볼, 약 80부터 크로스바, 86 이상은 넘어간다. 약하면 공이 느려서 골키퍼가 골대 끝까지 따라간다.
- **골키퍼**: 골라인 위를 좌우로 오간다. 킥 순간 **움직이던 쪽으로 몸이 쏠려**(최대 0.45m) 그쪽이 더 잘 막히고 반대쪽이 열린다. 닿는 범위는 `(1.0m + 5.3m/s × (공이 날아가는 시간 − 0.14초))`에 높은 공일수록 줄어든다(크로스바 높이에서 −28%).
- **골대**: 기둥·크로스바의 안쪽 절반에 맞으면 들어가고(골대 맞고 골), 바깥 절반은 튕겨 나온다.
- 그래서 선택이 생긴다. 구석을 높고 세게 노리면 골키퍼와 상관없이 들어가지만 조금만 어긋나면 골대 밖이고, 안전하게 차려면 골키퍼가 반대쪽으로 가는 순간을 기다려야 한다.

시뮬레이션 기준(수치는 직접 해 보며 맞춘다):

| 플레이 | 1번째 킥 | 5번째 킥 |
| --- | --- | --- |
| 골키퍼 반대쪽으로만 대충 찬다 | 약 50% | 약 33% |
| 가장 좋은 순간·자리를 알고 손 오차만 있다 | 약 95% | 약 82% |

조정할 곳은 `KEEPER`(쏠림·팔 길이·다이빙 속도·반응 시간·높이 손해)와 `penaltyKeepers`(진폭·주기·단계별 강화)다. 결과가 바뀌면 `tests/penalty-engine.test.ts`의 지문을 갱신하고 `ARCADE_RULES.penalty.engine`을 올린다.

### 서버가 무엇을 믿는가

씨앗(칸 번호)은 기기도 알기 때문에, 자유투와 마찬가지로 입력값을 지어내면 좋은 기록을 만들 수 있다. 친구끼리 쓰는 앱이라 자유투와 같은 수준으로 둔다. 서버는 입력의 범위와 형식을 검사하고 결과는 전부 다시 계산한다.

## 3. 파일

| 파일 | 내용 |
| --- | --- |
| `shared/penalty-engine.ts` | 골키퍼 다섯 명(`penaltyKeepers`), 골키퍼 위치(`keeperAt`), 킥 판정(`judgeKick`) |
| `src/penalty/render.ts` | 공 뒤에서 본 골대·골키퍼·공·그물(그림 파일 없이 캔버스로 그림) |
| `src/penalty/controller.ts` | 휘슬·시계·쓸어 올리기·공 비행·다이빙 재생 |
| `src/screens/Penalty.tsx` | 화면과 문구 |

세트·기록·API·원장은 컬링과 같은 `worker/arcade.ts`를 쓴다([컬링 계획](plan-curling.md) §3~4). 경로는 `/api/arcade/penalty`, 원장은 `penalty:set:<세트>:score` / `:gold`(사유 `승부차기 골`), 랭킹 분류 **승부차기**.

- 화면이 가려지거나 나가기 확인이 뜨면 멈추고, 돌아오면 **그 킥을 휘슬부터 다시** 시작한다.
