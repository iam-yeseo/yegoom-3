# 데일리 로또 17시 30분 전환 배포 안내

개선 PR 6은 판매 마감과 추첨을 17시에서 17시 30분으로 옮긴다. 새 마이그레이션은 없다. 기존 당첨 번호·표의 추첨일·정산 결과·지급 원장은 보존한다. 이 문서는 운영 시각을 정하기 위한 안내이며 이번 작업에서 원격 변경·머지·배포를 실행하지 않았다.

**17시 00분 이상~17시 30분 미만 KST에는 배포를 피한다.** 17시보다 여유 있게 앞서 배포를 완료하거나 17시 30분 이후에 반영한다. 구버전이 아직 추첨을 만들지 않았을 것이라고 가정해 이 시간대에 배포하지 않는다.

구버전은 17시 이후 bootstrap·상점 조회에서 오늘의 `lotto_draws`를 만들고 표를 정산할 수 있다. 이미 이 번호가 공개된 뒤 17시 10분에 새 버전을 배포하면, 새 판매 규칙은 17시 30분 전 구매를 오늘 회차로 받는다. 기존 추첨은 PK로 보존되므로 추가 표도 17시 30분 이후 그 번호로 정산된다. 번호를 미리 알고 살 수 있는 상태다. 새 UI가 17시 30분 전 번호를 숨겨도 이미 알려진 번호를 없애지는 못한다.

17시 30분 이후 반영하면 새 구매는 내일 회차다. 구버전이 17시에 끝낸 오늘 결과는 유지되며, 구버전이 17시~17시 30분에 이미 내일 회차로 판 표도 내일 표로 남는다. 표의 추첨일을 소급 변경하거나 회차를 다시 추첨하지 않는다. 정산은 기존 표별 `settled_at`과 UNIQUE 원장 reference로 중복 지급을 막는다.

운영 순서는 리뷰 → 시간대 확인 → 머지 → 배포다. 배포 뒤 기존 탭을 새로고침하고 홈·상점의 `17시 30분` 문구, 기존 표의 추첨일, 로또 화면의 기록을 확인한다. 안내 카드는 오늘 추첨 회차가 있고 17시 30분이 지난 경우에만 보이며 당첨 금액은 노출하지 않는다.

시간대를 잘못 골라 이미 공개된 회차와 추가 판매가 섞였다면 기록을 지우거나 원장을 직접 고치지 않는다. 당시 추첨 생성 시각·구매 시각·표의 draw_date·지급 reference를 보존해 별도로 확인한다. 이번 PR은 이런 회차의 판매 거절, 재추첨, 소급 재배정 정책을 추가하지 않는다.
