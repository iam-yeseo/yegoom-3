# 캐릭터 뽑기 인형 이미지 출처

2026-11-24(KST)에 사용자가 제공한 흰 배경의 JPEG 사진 15장을 지인용 비공개 서비스의 캐릭터 뽑기에 사용한다. 배포 파일은 `public/claw/dolls/doll-{type}.webp`이며, 원본 JPEG는 저장소 밖에 보관한다. 원본 번호 02~16에 순서대로 게임 번호(type) 1~15를 배정했다.

15장 모두 원본 JPEG에서 흰 배경과 열쇠고리를 제거했다. 사진 가장자리 픽셀의 색상 중앙값을 구하고, 밝기와 색차가 그 값에 가까운 영역을 바깥에서 따라가며 투명하게 처리했다. 분홍색 고리(1~13번)와 하늘색 고리(14·15번)는 색으로 구분했다. 고리 꼭대기와 연결된 플라스틱을 따라가고, 배경색이나 고리색에 가까운 경계까지 1픽셀 넓혀 제거했다. 분홍색 고리는 접점에 남은 가느다란 JPEG 테두리도 정리했다. 인형 바깥의 큰 갈고리와 작은 연결 고리를 지운 자리에는 기계 배경이 비쳐 보인다.

아래의 `y`는 원본 사진의 위에서부터 센 픽셀 좌표다. `CLIP_LIMITS`는 고리 색을 찾을 범위를 제한해 모자 장식이나 머리까지 함께 지우는 일을 막는다. 연결 끈이 플라스틱과 다른 색으로 보이는 곳은 `CORD_SPANS`에 그 범위를 따로 기록했다.

4번에서만 가려진 천을 복원했다. 끈 양옆에서 보이는 모자의 윗선을 이은 뒤, 가려진 영역을 바깥에서 안쪽으로 채웠다. 각 픽셀의 색은 주변 원본 천의 색을 가중 평균해 정했다. 원본 해상도에서 인형 몸 330,015픽셀 중 4,334픽셀(1.3133%)이며, 스크립트는 이 비율이 1.5%를 넘으면 중단한다. 축소할 때 분홍 테두리가 비치지 않도록 인접한 투명 영역 2픽셀까지 복원한 천 색을 연장했다.

인형과 떨어진 작은 조각을 제거하고 알파 경계를 부드럽게 했다. 알파가 24 이하인 픽셀과 투명 여백을 제거한 뒤 종횡비를 유지하면서 Lanczos로 긴 변을 320px로 줄였다. WebP 압축은 RGB 품질 85, `alpha_quality=100`, `method=6`, `exact=True`다. 저장한 파일을 다시 읽어 크기와 알파 채널을 대조하고 장당 40,000바이트 한도를 검사한다. 제작 환경은 Python 3.12.14, NumPy 2.3.5, Pillow 12.3.0, libwebp 1.6.0이다.

저장소 루트에서 아래 명령을 실행하면 인형 WebP 15장과 기계 배경색·어두운색·체크무늬 위에 놓은 모아보기 세 장을 생성한다.

```sh
python3 scripts/prepare-claw-dolls.py /tmp/claw-dolls-src --first-number 2 --preview /tmp/claw-rings-preview
```
