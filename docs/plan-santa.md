# 예굼방 아케이드 3 — 산타 선물 배달 계획 (초안)

크리스마스 기간 한정 혼자 하기 게임. 산타와 루돌프가 썰매를 타고 하늘을 날며, 타이밍에 맞춰 **[선물 던지기]** 를 눌러 집 10곳의 굴뚝에 선물을 넣는다. 자유투 대결과 같은 원칙을 따른다: **같은 타이밍이면 언제나 같은 결과**, 서버가 똑같이 다시 계산해서 기록한다.

> 상태: 계획 단계. §1은 사용자가 정한 것, §2부터는 제안이며 §7의 미정 항목을 정한 뒤 확정한다.

## 1. 정해진 것 (2026-11-10)

| 항목 | 내용 |
| --- | --- |
| 진행 | 산타 출발! → 썰매가 하늘을 날며 집 10곳을 차례로 지나감 |
| 조작 | [선물 던지기] 버튼 하나. 누르면 선물이 떨어지고, 타이밍이 맞아야 굴뚝에 들어감 |
| 난이도 | 굴뚝 높이를 집마다 다르게 → 떨어지는 거리가 달라서 던질 타이밍도 매번 다름 |
| 점수 | 굴뚝에 정확히 들어가면 점수. 10곳 전부 성공하면 보너스 **+3점** |
| 골드 | 배달을 완료하면 **100G** |
| 횟수 | 오전·오후 **1번씩** |
| 연습 모드 | 없음 |
| 기간 | 크리스마스 기간 한정 |
| 그림 | 사용자가 이미지 생성기로 만들어 제공 (§6) |

## 2. 게임 한 판 (제안)

- 세로 화면. 썰매는 화면 위쪽 같은 높이에 떠 있고, 집들이 오른쪽에서 왼쪽으로 흘러온다(배경이 움직여서 썰매가 나는 것처럼 보임).
- 집 하나마다 **선물은 한 번만** 던질 수 있다. 던지지 못하고 집을 지나치면 그 집은 미배달.
- 떨어지는 선물은 썰매의 앞으로 가던 속도를 그대로 가지고 포물선으로 떨어진다. 그래서 굴뚝 바로 위가 아니라 **조금 앞에서** 던져야 한다.
  - 굴뚝이 높으면(지붕 위로 많이 솟음) 떨어지는 시간이 짧아 굴뚝 가까이에서,
  - 굴뚝이 낮으면 더 멀리서 미리 던져야 한다. 이것이 "높이가 달라서 쉽지 않은" 이유가 된다.
- 판정: 선물이 굴뚝 입구 높이를 지날 때 선물 전체가 입구 안쪽이면 성공. 입구 테두리에 걸리면 튕겨 나가며 "아깝다!", 아예 빗나가면 지붕에 떨어진다.
- 매 집이 끝나면 짧게 결과를 보여 준다: `배달 성공!` / `조금 빨랐어요` / `조금 늦었어요`. 연습 모드가 없으니 한 판 안에서 감을 잡을 수 있게, 빨랐는지 늦었는지만 알려 주고 정답 위치는 보여 주지 않는다.
- 10번째 집이 끝나면 결과 화면: 성공 수, 보너스, 받은 점수·골드.

### 2-1. 난이도 장치
- **굴뚝 높이**: 5단계(아주 낮음~아주 높음). 한 판의 10곳은 섞어서, 같은 높이가 세 번 넘게 연속으로 나오지 않게.
- (선택) **속도**: 뒤로 갈수록 썰매가 조금씩 빨라짐(1번 집 대비 10번 집 +15% 정도). 넣을지는 §7.
- (선택) **굴뚝 폭**: 처음엔 고정. 너무 쉬우면 좁힌다.
- 성공 구간의 시간 폭은 처음에 **±80ms 안팎**으로 시작해서 직접 해 보며 맞춘다(자유투처럼 숫자는 한곳에 모음).

### 2-2. 코스
- 같은 오전/오후 칸에서는 **모든 플레이어가 같은 코스**(집 순서·굴뚝 높이)를 받는다. 칸 번호로 정해지는 결정적 난수라서 서버에 따로 저장할 필요가 없고, 친구끼리 같은 조건에서 비교할 수 있다.
- 코스는 시작을 누른 뒤에만 보인다(미리 보고 외우기 방지).

## 3. 규칙 (제안)

| 항목 | 제안 |
| --- | --- |
| 칸 | KST **오전 00:00~11:59**, **오후 12:00~23:59**. 칸마다 1판, 남은 판은 이월 없음 |
| 기회 사용 | [산타 출발!]을 누르는 순간 그 칸의 기회를 씀 (자유투 세트 시작과 같음) |
| 점수 | 굴뚝 성공 1곳마다 **1점**, 10곳 전부면 **+3점** → 한 판 최대 13점 |
| 골드 | 10곳을 모두 지나면(던졌든 못 던졌든) **100G** |
| 중간에 나감 | 던진 결과는 그때그때 서버에 기록. 다시 들어오면 다음 집부터 이어서 함 |
| 마감 | 칸이 끝난 뒤 10분까지 마저 할 수 있음. 그래도 남은 집은 미배달로 처리 |
| 운영자 | 볼 수만 있고 플레이는 403 (자유투와 같음) |
| 랭킹 | 새 분류 **산타 배달**(짧게 `산타`). 원장 사유 `산타 선물 배달` |
| 기간 밖 | 홈·게임 탭 타일을 숨김. 시작 요청은 서버가 거절 |

## 4. 구현 메모 (자유투 대결 구조 재사용)

| 파일 | 내용 |
| --- | --- |
| `shared/santa-engine.ts` | 결정적 계산. 입력은 집마다 **던진 시각(그 집 접근 시작부터 ms, 정수)** 하나. 코스 생성(칸 번호 → 높이 10개), 낙하 위치, 판정 |
| `shared/balance.ts` | `SANTA_RULES`(기간, 칸 길이, 집 수, 점수·보너스·골드, 판정 폭, 엔진 버전) |
| `migrations/00xx_santa.sql` | `santa_runs`(사용자·칸 유일, 요청 번호 유일, 엔진 버전, 진행 집 수, 성공 수), `santa_drops`(판·몇 번째 집 유일, 던진 시각, 결과) |
| `worker/santa.ts` | 상태 조회, 판 시작, 던지기 기록(서버 재계산·원장), 홈 요약 |
| `src/santa/*`, `src/screens/Santa.tsx` | 캔버스 그리기·입력·효과음, 화면 |
| `shared/ranking-periods.ts` | `santa:` 접두어 → 산타 배달 |

- 계산은 사칙연산과 `Math.sqrt`만 사용(포물선 낙하는 식 하나로 끝나서 프레임 시뮬레이션도 필요 없음). 화면 애니메이션만 프레임으로 그린다.
- 던지기는 누르는 순간 서버로 보내고, 응답 전까지 기기에 저장해서 새로고침으로 다시 던질 수 없게 한다(자유투 §3-3과 같음).
- 타이밍은 브라우저에서 재는 값이라 이론상 조작할 수 있다. 자유투와 같은 수준(값 범위·순서 검증, 서버 재계산)으로 둔다.

## 5. 도전과제 (아이디어, 미확정)

확정되면 운영 시트 `도전과제` 탭(유형 `게임하기`)에 먼저 넣고 코드에 반영한다.

| 달성조건 | 제목 후보 |
| --- | --- |
| 산타 선물 배달 첫 참여 | 루돌프 코가 빨개지도록 출발! |
| 한 판 10곳 전부 성공 | 굴뚝 장인, 택배 회사가 스카우트 시도 |
| 한 판 0곳 성공 | 선물은 마음이 중요한 거래요 |

## 6. 필요한 그림 (이미지 생성기용)

모두 **투명 배경 PNG**, 정사각형이 아니어도 됨. 받은 뒤 자유투처럼 여백을 자르고 WebP로 줄인다.

| 그림 | 설명 | 요청 크기 |
| --- | --- | --- |
| 썰매 | 산타 + 루돌프 + 썰매, **옆모습, 오른쪽을 향해** 나는 모습 | 가로 1536 이상 |
| 선물 상자 | 리본 달린 상자 2~3가지 색 (따로따로) | 512 |
| 집 | 지붕까지 있는 집 3~4종, **굴뚝 없이** | 1024 |
| 굴뚝 | 벽돌 굴뚝 1개, **세로로 길게**, 위 입구가 살짝 보이게 | 세로 1536 |
| 배경 | 눈 오는 밤하늘·달·별, **좌우가 이어지게**(가로 반복) | 가로 2048 |
| 홈 타일 | 홈 화면 아이콘 (선물 든 산타 또는 썰매) | 1024 |

- 굴뚝을 따로 받는 이유: 긴 굴뚝 하나를 집 지붕 뒤에 두고 얼마나 솟아 보이게 할지로 높이를 바꾼다. 그림 한 장으로 5단계 높이를 모두 만든다.
- 공통 프롬프트 예: `cute flat cartoon illustration, soft pastel colors, thick dark outline, simple shapes, transparent background, no text`. 기존 자유투 타일과 같은 그림체를 맞추려면 그 그림을 함께 참고 이미지로 넣는다.

## 7. 정해야 할 것

1. **이벤트 기간**: 예) 12/1~12/25, 12/18~12/25, 12/24~12/25 중 어느 것? 기간이 끝난 뒤 기록판은 남겨 둘지.
2. **굴뚝 1곳당 점수**: 1점이 맞는지 (10곳 성공 시 10 + 3 = 13점).
3. **100G 조건**: 10곳을 다 지나기만 하면 지급인지, 성공 수와 상관있는지(예: 1곳 이상 성공).
4. **오전/오후 기준**: 00~12시 / 12~24시로 나누는 게 맞는지.
5. **같은 칸 같은 코스**: 모두 같은 코스로 할지, 사람마다 다르게 할지.
6. **속도 증가**: 뒤로 갈수록 빨라지는 것을 넣을지.
7. **오늘의 기록판**: 자유투처럼 오늘 다른 사람 기록을 보여 줄지.
