# 디자인 기준

사용자가 제공한 `예굼방 게임 화면.html`은 9개 휴대전화 화면을 나열한 디자인 캔버스다. 원본은 custom template/runtime으로 묶여 있어 HTML·스타일·로컬 폰트·이미지를 복원한 뒤 React 컴포넌트로 구현했다. 해당 런타임이나 외부 스크립트를 서비스에 넣지 않았다.

기상시간 입력, 행운 점수 입력, 퇴근 결과, 캐치마인드 맞히기/결과/그리기, 쿠지, 뽑기/성공 화면을 기준으로 삼았다. 원본에 없는 홈·로그인·프로필·랭킹은 같은 색상과 컴포넌트 규칙으로 구성했다. 실제 휴대전화에서는 OS 상태바가 표시되므로 원본의 가짜 9:41·배터리 영역은 앱 내부에 중복해서 넣지 않았다.

캐릭터 8종은 ZIP과 HTML 내 에셋이 바이트 단위로 같았다. 제공된 PNG 원본을 그대로 `public/characters`에 넣었다. 원본은 투명 배경이 아닌 크림색 배경의 RGB 이미지이며 시안과 같은 `mix-blend-mode:multiply`를 사용한다. 현재 애니메이션은 CSS의 가벼운 움직임이며 `prefers-reduced-motion`을 지원한다. 최종 투명 캐릭터나 Rive/Lottie는 후속 작업이다.

Pretendard 라이선스는 `public/fonts/OFL.txt`에 포함한다. 캐릭터는 사용자 제공 자료로서 별도 재배포 라이선스를 임의 부여하지 않는다. 앱 아이콘은 별도 SVG로 만들었으며 `scripts/build-icons.mjs`로 PNG를 재생성할 수 있다.
