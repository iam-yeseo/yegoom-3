# 예굼방 오늘의 게임 — 변기 폭파

해적 룰렛을 모티브로 한 같이 하는 게임. 한 명씩 돌아가며 같은 행동(볼일 보고 물 내리기)을 하다가, 변기가 넘쳐 터지는 차례의 사람이 진다. 빙고처럼 **실시간이 아니다**: 각자 접속했을 때 자기 차례를 처리한다.

> 상태: 구현 완료(2026-11-23). 그림 7장도 같은 날 받아 넣었다([이미지 프롬프트](toilet-image-prompts.md), [출처 기록](asset-provenance.md)). 그림을 불러오지 못하면 이모지가 대신 나온다. 도전과제는 아직 없다.

## 1. 확정된 결정 (2026-11-23)

| 항목 | 결정 |
| --- | --- |
| 판 | 하루 두 판. 오전 00:00~12:00, 오후 12:00~23:50(KST) |
| 참가 | 활성 플레이어 전원 자동 참가. 판의 첫 누르기 때 명단과 순서가 고정된다 |
| 순서 | 아이디 순서를 판마다 한 칸씩 돌린다(1-2-3 → 2-3-1 → 3-1-2). 오전·오후·다음 날로 이어진다 |
| 터지는 방식 | **갈수록 위험해짐**. 한 판은 `참가자 수 × 3`칸이고 그중 한 칸에서 반드시 터진다. 다음 누르기가 터질 확률은 `1 / 남은 칸` |
| 점수 | 터진 차례의 사람 -10점, 나머지 참가자 +5점. 터지는 순간 지급 |
| 멈춘 차례 | 빙고처럼 10분 넘게 멈춘 차례는 다른 참가자가 넘길 수 있다 |
| 안 터지면 | 판이 끝날 때까지 안 터지면 그 판은 무효(점수 없음) |

정해 주지 않아 기본값으로 둔 것(바꾸려면 `shared/balance.ts`·`TOILET_RULES`):

- **넘기기 = 대신 누르기**: 차례를 그냥 건너뛰면 자리를 비운 사람이 위험을 피하고 +5점만 받게 되므로, 넘기는 사람이 **그 사람 대신 누른다**. 그 누르기에서 터지면 원래 차례인 사람이 진다. 모든 칸이 그 칸의 주인에게 그대로 남아서 누구나 같은 확률(1/참가자 수)로 진다.
- **첫 차례**: 판이 열린 시각(0시·12시)부터 기다린 것으로 본다. 그래서 0시 10분부터는 깨어 있는 사람이 첫 차례를 대신 누를 수 있다.
- **칸 수**: 한 사람당 3칸(`slotsPerPlayer`). 3명이면 9번 안에 터진다.
- **중간에 들어온 사람**은 다음 판부터, **비활성이 된 사람**은 차례를 건너뛰고 점수도 받지 않는다(진 사람은 예외).
- **불안한 변기**: 다음에 터질 확률이 25% 이상이면 떨리는 그림으로 바뀐다(`nervousChance`).
- 2명보다 적으면 판이 열리지 않는다.

## 2. 서버 (`worker/toilet.ts`)

| 표 | 내용 |
| --- | --- |
| `toilet_rounds` | 판 하나에 한 줄(`YYYY-MM-DD:am|pm`). 첫 누르기에 생긴다. 순서·칸 수·누른 기록·다음 차례·상태(`playing`·`burst`)·진 사람·정산 결과·토큰 |

- 판이 아직 없으면(아무도 안 누름) 상태는 규칙만으로 계산한다: 활성 플레이어와 판 번호로 순서를 만들고, 첫 차례는 판이 열린 시각부터 기다린 것으로 본다.
- 무효는 저장하지 않는다. `playing`인 채로 판 시간이 지나면 화면이 무효로 보여 준다.
- 누르기는 화면이 본 **누른 횟수**를 함께 보내고, 서버는 그 횟수가 그대로일 때만 적용한다(첫 판은 `INSERT … ON CONFLICT DO NOTHING`, 그 뒤는 `UPDATE … WHERE push_count = ?`). 동시에 두 번 누르거나 두 번 탭해도 하나만 적용되고 나머지는 409(`CHANGED`).
- 터질지는 서버가 `crypto.getRandomValues`로 정한다. 기기에는 결과만 간다.
- 원장: `toilet:<판>:<사용자>:score`, 사유 `변기 폭파 오전 · 펑!` / `… · 생존`. 랭킹 분류 **변기 폭파**.
- 알림: 다음 차례인 사람에게 `turn`/`toilet`, 터지면 참가자 모두에게 `toilet`(내 점수).
- API: `GET /api/toilet[?since=<도장>]`(바뀐 게 없으면 한 줄만 읽고 `unchanged`), `POST /api/toilet/push`, `POST /api/toilet/skip`. 입력은 `{ roundId, pushes }`.
- 화면은 보이는 동안만 조회한다: 판이 진행 중이면 5초, 아니면 15초.
